# Spokane retail vacancy by quarter, as revised in ACTIV8's Q3 2026 report. Pulled 2026-11-16.

Source: ACTIV8 Real Estate, Spokane Retail Market Report Q3 2026
(CoStar data, pulled by ACTIV8 October 14, 2026), five-quarters table.
https://www.activ8re.com/spokane-retail-market-report-q3-2026/

Why this series is short: CoStar's long vacancy history is proprietary,
and ACTIV8 began publishing quarterly Spokane retail reports in 2025.
Earlier quarters exist only in each old report as first published; CoStar
revises back-quarters, so mixing first-published numbers with revised
ones would make a false trend. This file keeps one vintage: the Q3 2026
report's own table.
